# 🏏 Cricket World Cup Archive

An interactive, responsive landing page showcasing Cricket World Cup history with modern UI/UX.

## ✨ Features

- ✅ **Fixed Navigation Menu** - Changes color/style on scroll
- ✅ **Interactive Hover Effects** - Menu items animate on hover
- ✅ **Fully Responsive** - Works on all devices
- ✅ **Dynamic Image Slider** - Auto-rotating hero images
- ✅ **3D Card Effects** - Hover animations
- ✅ **Animated Statistics** - Count-up numbers
- ✅ **Glass Morphism Design** - Modern aesthetic

## 🛠️ Tech Stack

- React 18 + Vite
- CSS3 with custom properties
- Font Awesome 6
- Google Fonts (Poppins)

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/ankitparida-dev/SCT_WD_1.git

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
